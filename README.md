# 💼 취업 정보 서비스 프로젝트 계획서

## 1. 프로젝트 개요
다양한 소스(PDF, URL, Email)에서 채용 정보를 추출하여 체계적으로 관리하고 사용자에게 제공하는 웹 서비스입니다. AI(Gemini API)를 활용하여 비정형 데이터에서 정형 데이터를 추출하는 것이 핵심입니다.

## 2. 주요 기능
- **정보 수집 및 추출**:
    - PDF 파일 업로드 및 텍스트 추출.
    - URL 입력 시 웹 크롤링을 통한 정보 수집.
    - 이메일 본문 복사-붙여넣기 및 정보 추출.
    - 소스 내에 URL이 포함된 경우 해당 사이트 자동 방문 및 추가 정보 수집.
- **관리자 기능**:
    - 추출된 정보의 검토, 수정, 승인 및 DB 저장.
    - 채용 공고의 수동 등록, 수정, 삭제.
- **사용자 기능**:
    - 승인된 채용 공고 목록 조회 및 상세 정보 확인.
    - 회사명, 지역 등을 활용한 검색 및 필터링.

## 3. 기술 스택
- **Frontend**: React (Vite) + TypeScript + Vanilla CSS
- **Backend**: FastAPI (Python)
- **Database**: SQLite
- **AI/ML**: Gemini API (정보 추출 및 요약)
- **Libraries**:
    - `PyMuPDF` (PDF 분석)
    - `Playwright` or `BeautifulSoup` (웹 크롤링)

## 4. 아키텍처 및 데이터 모델
- **JobInfo 모델**:
    - id, 회사명, 공고 제목, 지원 요건, 지원 기간, 지원 방법, 근무지, 급여, 출처 URL, 상태(검토/승인)

## 5. 단계별 구현 계획
1.  **Step 1**: 프로젝트 기본 구조 및 환경 설정 (FastAPI + React)
2.  **Step 2**: Gemini API 연동 및 정보 추출 로직 개발
3.  **Step 3**: PDF 파싱 및 웹 크롤링 기능 구현
4.  **Step 4**: 백엔드 API 및 데이터베이스 연동
5.  **Step 6**: 프론트엔드 UI 개발 (목록, 상세, 관리자 페이지)
6.  **Step 7**: 전체 시스템 통합 및 테스트
