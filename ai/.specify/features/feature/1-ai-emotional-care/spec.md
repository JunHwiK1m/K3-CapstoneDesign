# 기능 명세: 능동형 AI 감정 케어 에이전트

## 1. 개요
본 기능은 사용자의 일상 기록(텍스트 및 음성)을 분석하여 실시간 감정 맥락을 파악하고, 사용자의 정서적 안정과 성장을 돕기 위한 맞춤형 솔루션(음악, 영화, 식단, 조언 등)을 선제적으로 제안하는 능동형 AI 에이전트 시스템을 구축하는 것입니다. 분석 결과는 백엔드 시스템으로 전달되어 사용자 인터페이스에 반영됩니다.

## 2. 사용자 시나리오
1. **기록 단계**: 사용자가 텍스트를 입력하거나, 마이크를 통해 실시간으로 음성 일기를 들려줍니다.
2. **대화 단계 (통화 모드)**: AI가 먼저 안부를 묻고, 사용자의 말에 짧고 다정하게 공감하며 대화를 이어갑니다. (2.5초 침묵 감지 적용)
3. **분석 단계**: 대화가 종료(키워드 감지)되는 즉시 AI가 전체 맥락을 분석하여 감정 지표를 산출합니다.
4. **제안 및 위로**: 분석 결과를 바탕으로 텍스트 리포트와 플랫폼 딥링크를 출력하고, 따뜻한 목소리(TTS)로 최종 위로 메시지를 전달합니다.
5. **결과 확인**: 사용자는 한눈에 들어오는 감정 요약과 추천 선물을 확인하며 정서적 안정을 얻습니다.

## 3. 기능 요구사항
- [x] **실시간 음성 상호작용**: Whisper(STT)와 OpenAI Audio(TTS)를 연동하여 지연 시간 없는 대화 경험을 제공해야 한다.
- [x] **종합 감정 리포트**: 통화 세션 전체를 요약하여 기쁨, 슬픔, 스트레스 지수를 도출해야 한다.
- [x] **플랫폼 특화 딥링크**: Spotify 및 Netflix 검색 규격에 맞는 URL을 자동 생성해야 한다.
- [x] **간결한 피드백**: UI 공간 효율을 위해 음성 피드백은 최대 2줄 이내로 제한해야 한다.
- [ ] **데이터 모델링 연동**: (진행 중) 산출된 JSON 결과를 실제 DB 모델(`Emotions`, `Recommendations`)에 영속화하는 로직을 최종 점검한다.
...
- 데이터 암호화 및 인프라 보안 구현은 백엔드 담당 영역으로 간주한다.
- AI 에이전트는 특정 플랫폼(Spotify, Netflix)에 한해 예측 가능한 검색 URL 구조를 사용하여 딥링크를 생성한다.
- 정책 변화에 대비하여 딥링크 생성 로직은 코드상에서 분리되어 관리가 용이해야 한다.

## 4. 예외 처리 (Edge Cases & Error Handling)
- [ ] **분석 실패 및 데이터 부족**: 사용자의 입력 데이터가 지나치게 적거나 기술적 이유로 분석이 불가능한 경우(`analysis_status: FAILED`), 에러를 노출하는 대신 기본값 기반의 범용 격려/공감 메시지와 대중적인 추천 콘텐츠를 출력하여 서비스 경험의 연속성을 보장해야 한다.

## 5. 성공 기준 (Success Criteria)
- [ ] **지표 정확도**: 산출된 3종 감정 지표가 사용자의 실제 감정 상태와 80% 이상의 상관관계를 보여야 한다.
- [ ] **스키마 정합성**: 모든 AI 생성 데이터가 백엔드 DB 스키마의 제약 조건(소수점 자리수, ENUM 타입 등)을 100% 준수해야 한다.
- [ ] **응답 속도**: 통합 분석 및 추천 데이터 생성 프로세스가 5초 이내에 완료되어야 한다.

## 6. 데이터 엔티티 (Entities - 구현 완료)
- **Journals**: `src/models/db_entities.py`에 구현됨. 일기 본문(암호화), 음성/사진 경로, 분석 상태 포함.
- **Emotions**: `src/models/db_entities.py`에 구현됨. 기쁨, 슬픔, 스트레스 개별 수치(-9.9999~9.9999) 및 요약문.
- **Recommendations**: `src/models/db_entities.py`에 구현됨. 추천 카테고리, 제안 문구, 핵심 키워드 메타데이터 포함.
- **UserSettings**: `src/models/db_entities.py`에 구현됨. 사용자별 조언 말투, 페르소나 스타일 설정.

## 8. 가정 및 제약 사항
