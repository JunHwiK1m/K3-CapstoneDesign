# 기술 연구 결과 보고서 (Research)

## 1. LLM 모델 선정
- **결정:** Qwen (사용자 요청 기반)
- **근거:** 한국어 이해도가 높고, 감정 분석 및 상황 요약 작업에 적합한 추론 능력을 보유함.
- **대안:** GPT-4, Llama 3 (향후 확장성 고려)

## 2. 음성 분석 (STT) 기술
- **결정:** OpenAI Whisper + librosa
- **근거:** Whisper는 다양한 환경의 음성을 텍스트로 고품질 변환(STT)하며, librosa를 통해 목소리 톤(음향 특징)을 분석하여 감정 분석 보조 지표로 활용 가능.

## 3. 실행 판단 및 출력 제어
- **결정:** 텍스트 기반 구분자 파싱 (가수*#*곡명)
- **근거:** 백엔드 시스템과의 단순하고 명확한 인터페이스를 위해 정해진 구분자를 활용한 문자열 반환 방식을 채택.

## 4. 보안 설계
- **결정:** 백엔드 암호화 필드(Journals.content) 준수
- **근거:** 민감한 일기 본문은 백엔드에서 암호화되어 저장되므로, AI 에이전트는 복호화된 컨텍스트 내에서만 분석을 수행하고 결과만 반환함.
