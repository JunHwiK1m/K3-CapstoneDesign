# 기술 설계 및 구현 계획: 능동형 AI 감정 케어 에이전트

## 1. 기술 컨텍스트 (Technical Context)
- **주요 기술 스택:** OpenAI GPT-4o (LLM), OpenAI Whisper (STT), OpenAI Audio (TTS), winsound/pydub (윈도우 오디오 제어)
- **의존성:** 윈도우 FFmpeg (필수), OpenAI Python SDK
- **미해결 사항:** 없음 (실시간 통화 모드 및 종합 분석 로직 구현 완료)

## 2. 프로젝트 헌장 준수 확인 (Constitution Check)
- [x] **한국어 중심:** 모든 프롬프트, 분석 결과 및 문서는 한국어로 작성됨.
- [x] **TDD 원칙:** 분석 엔진 및 파싱 로직에 대한 단위 테스트 15종 통과.
- [x] **보안 최우선:** API 키 환경 변수 관리 및 백엔드 암호화 규격 준수.

## 3. 구현 아키텍처
### 음성 분석 및 합성 파이프라인 (실시간 통화 모드)
1. **마이크 입력 (PyAudio)**: 사용자 음성 실시간 캡처.
2. **침묵 감지 (SpeechRecognition)**: 2.5초 이상 침묵 시 발화 종료 판단 (자연스러운 대화 유도).
3. **음성 인식 (Whisper)**: 음성을 텍스트로 변환 (CPU 환경 최적화, FP32).
4. **실시간 응답 (GPT-4o Chat)**: 짧은 공감형 텍스트 생성 (1~2문장 제한).
5. **음성 합성 (OpenAI TTS)**: 응답 텍스트를 목소리로 변환 및 재생 (`winsound` 데드락 방지 로직 적용).
6. **종합 분석 (GPT-4o JSON)**: 통화 종료 후 전체 기록을 바탕으로 감정 지표 및 맞춤 제안 생성.

## 4. 상세 설계 및 인터페이스
