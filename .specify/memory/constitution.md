# capStone 프로젝트 헌장

## 개요
이 문서는 capStone 프로젝트의 핵심 원칙과 거버넌스 가이드라인을 정의합니다. 모든 개발, 의사결정 및 산출물 작성은 본 헌장을 준수해야 합니다.

## 원칙

### 한국어 중심 소통 및 산출물 작성
모든 프로젝트 산출물(문서, 코드 주석, 커밋 메시지 등)과 에이전트 대화는 반드시 한글로 진행되어야 합니다.
**근거:** 명확한 의사소통을 보장하고, 요구사항 및 명세에 대해 모든 참여자가 동일한 이해를 갖추기 위함입니다.

### 테스트 중심 개발 (TDD)
모든 기능 개발과 버그 수정은 테스트 중심 개발(Test-Driven Development) 원칙을 따릅니다.
**근거:** 코드 품질을 높이고 리팩토링 시 안정성을 확보하며, 예기치 않은 회귀(regression) 결함을 조기에 방지하기 위함입니다.

### 보안 최우선 (Security First)
사용자의 개인정보 및 민감한 데이터를 다루는 프로젝트이므로, 아키텍처 설계부터 구현, 배포에 이르는 모든 과정에서 보안을 최우선으로 고려해야 합니다.
**근거:** 민감한 사용자 데이터 유출을 방지하고 시스템의 신뢰성을 유지하며, 관련 보안 규제를 엄격히 준수하기 위함입니다.
